\begin{abstract}
This report presents MoodMirror, a lightweight facial expression recognition system that classifies seven emotions from FER2013 grayscale facial images. The design goal is to provide a practical middle ground between two extremes: very large models that can perform strongly on FER benchmarks but are computationally expensive, and very small lightweight models that are efficient but often suffer noticeable performance degradation. In particular, this project targets realistic household and ordinary PC deployment, so model quality is evaluated together with CPU inference practicality rather than accuracy alone.

To realize this objective, we compare three principal paths: HOG plus SVM as the classical baseline, SimpleCNN as the deep learning baseline, and LiteCNN as the proposed lightweight architecture, with a CLCM-style model used as the replication comparison baseline. The integrated pipeline includes a unified data loader, reproducible training and evaluation scripts, model artifact loading, and a Streamlit-based demonstration interface supporting image upload, webcam snapshot, and live video inference with intelligent sampling.

On currently verified repository artifacts, test accuracy results are 43.23\% for HOG plus SVM, 60.39\% for CLCM, and 65.88\% for LiteCNN. LiteCNN remains within the project parameter budget at 900,903 trainable parameters and outperforms CLCM by 5.49 percentage points on test accuracy in the present checkpoint set. This aligns with the proposal direction: exceed CLCM performance while staying under the predefined lightweight parameter threshold so deployment remains feasible on an ordinary CPU-based system.

The report documents achieved outcomes, unresolved gaps, and final submission readiness. Core goals for integration and comparative benchmarking are met. Remaining optimization work is centered on freezing a reproducible LiteCNN checkpoint at or above the 70\% target and completing final standardized latency and ablation tables under controlled hardware conditions.
\end{abstract}

\section{Introduction}

\subsection{Motivation}
Facial expression recognition remains a challenging visual classification problem due to intra-class variation, inter-class ambiguity, illumination changes, and occlusions. In education and practical deployment contexts, model design must balance predictive performance against computational efficiency. The project therefore targets lightweight architectures suitable for CPU-constrained use while preserving competitive recognition quality.

As illustrated in presentation materials, the same verbal message can convey entirely different meanings depending on facial expression. This motivates the development of robust, deployable emotion recognition systems for real-world applications including driver drowsiness detection, employee wellbeing monitoring, and mental health support.

\subsection{Problem Statement}
Given an input face image, predict one of seven emotion classes:
\begin{itemize}[leftmargin=*]
    \item angry
    \item disgust
    \item fear
    \item happy
    \item sad
    \item surprise
    \item neutral
\end{itemize}

The challenge lies in finding the "usable middle" between two deployment extremes:

\begin{itemize}[leftmargin=*]
    \item \textbf{Ultra-Lightweight Models}: Optimized for low-power hardware but typically sacrifice accuracy
    \item \textbf{Heavyweight Architectures}: High accuracy (ResNet-50: 25.6M parameters, EfficientNet-B7: 66.7M parameters, DCNN Ensemble: 600MB+) but computationally prohibitive for real-time CPU deployment
\end{itemize}

This project targets CPU-based household deployment with models under 1.5M parameters and sub-10ms inference latency.

\subsection{Project Objectives}
From the approved proposal, objectives are:
\begin{itemize}[leftmargin=*]
    \item O1: Build a complete FER pipeline (preprocessing, training, evaluation, and demo)
    \item O2: Establish HOG plus SVM and SimpleCNN baselines
    \item O3: Build LiteCNN with less than 1.5M parameters, less than 10 ms CPU inference target, and at least 70\% accuracy target
    \item O4: Conduct ablation-guided optimization analysis
    \item O5: Deliver an interactive demonstration interface with intelligent webcam sampling
    \item O6: Beat the CLCM lightweight baseline
\end{itemize}

\section{Methods}

\subsection{HOG plus SVM Baseline}
The classical baseline extracts Histogram of Oriented Gradients (HOG) descriptors and trains a linear Support Vector Machine (SVM) classifier. This approach represents traditional computer vision methods before the deep learning era.

\subsubsection{HOG Feature Extraction}
HOG descriptors capture local edge orientation patterns:
\begin{itemize}[leftmargin=*]
    \item Orientation bins: 9
    \item Pixels per cell: (8, 8)
    \item Cells per block: (2, 2)
    \item Feature dimension: approximately 900 features per image
\end{itemize}

\subsubsection{SVM Configuration}
A LinearSVC classifier with C=1.0 regularization is trained on the extracted HOG features. Hyperparameter tuning across 12 configurations showed that the default parameters (9 orientations, 8×8 pixels per cell, 2×2 cells per block) performed best at 43.23\% test accuracy. The best tuned configuration (CLAHE preprocessing, 8 orientations, 3×3 blocks) achieved 42.77\%, slightly worse than default, confirming the baseline configuration's effectiveness.

\subsubsection{SVM Configuration}
A LinearSVC classifier with C=1.0 regularization is trained on the extracted HOG features. This baseline anchors performance against non-deep-learning approaches and provides a computational efficiency reference point.

\subsection{SimpleCNN Baseline}
SimpleCNN implements a straightforward four-block convolutional architecture serving as the deep learning baseline. The model follows a standard CNN design pattern with progressive feature extraction.

\subsubsection{Architecture Details}
The SimpleCNN architecture consists of:
\begin{itemize}[leftmargin=*]
    \item \textbf{Input}: 1×48×48 grayscale image
    \item \textbf{Conv Block 1}: 32 filters, 3×3 kernel, stride 1, padding 1 → BatchNorm → ReLU → MaxPool(2×2)
    \item Output: 32×24×24
    \item \textbf{Conv Block 2}: 64 filters, 3×3 kernel → BatchNorm → ReLU → MaxPool(2×2)
    \item Output: 64×12×12
    \item \textbf{Conv Block 3}: 128 filters, 3×3 kernel → BatchNorm → ReLU → MaxPool(2×2)
    \item Output: 128×6×6
    \item \textbf{Conv Block 4}: 256 filters, 3×3 kernel → BatchNorm → ReLU → MaxPool(2×2)
    \item Output: 256×3×3
    \item \textbf{Global Average Pooling}: 256×3×3 → 256×1×1
    \item \textbf{Fully Connected}: 256 → 7 classes
\end{itemize}

\textbf{Total trainable parameters}: 390,599

\textbf{Key characteristics}:
\begin{itemize}[leftmargin=*]
    \item Standard sequential convolution operations
    \item Batch normalization for training stability
    \item Dropout (p=0.25) for regularization
    \item Simple and interpretable design
\end{itemize}

\subsection{LiteCNN Proposed Model}
LiteCNN represents the project's primary contribution, designed as an efficiency-focused redesign that maintains accuracy while reducing computational cost through depthwise separable convolutions and residual learning.

\subsubsection{Architecture Details}
The LiteCNN architecture employs:
\begin{itemize}[leftmargin=*]
    \item \textbf{Input}: 1×48×48 grayscale image
    \item \textbf{Initial Conv}: 32 filters, 3×3 kernel, stride 1 → BatchNorm → ReLU
    \item Output: 32×48×48
    \item \textbf{Residual Block 1} (×2): Depthwise separable 48@24×24 with skip connection
    \item \textbf{Residual Block 2} (×2): Depthwise separable 96@12×12 with skip connection  
    \item \textbf{Residual Block 3} (×3): Depthwise separable 192@6×6 with skip connection
    \item \textbf{Residual Block 4} (×2): Depthwise separable 384@3×3 with skip connection
    \item \textbf{Global Average Pooling}: 384×3×3 → 384×1×1
    \item \textbf{Fully Connected}: 384 → 7 classes
\end{itemize}

\textbf{Total trainable parameters}: 900,903

\subsubsection{Key Innovations}
\begin{itemize}[leftmargin=*]
    \item \textbf{Depthwise Separable Convolutions}: Factorizes standard convolutions into depthwise (spatial) and pointwise (channel-wise) operations, reducing computational cost
    \item \textbf{Residual Connections}: Skip connections enable gradient flow and feature reuse
    \item \textbf{Progressive Channel Expansion}: Gradually increases feature channels (32→48→96→192→384) while reducing spatial dimensions
    \item \textbf{Lightweight Classifier}: Single fully connected layer from global pooling
\end{itemize}

\section{Ablation Studies and Optimization Analysis}

To understand the impact of various design decisions and hyperparameters, we conducted systematic ablation studies on the SimpleCNN baseline. Each experiment isolated a single variable while keeping all other settings constant.

\subsection{Experimental Design}
Five ablation experiments were conducted:
\begin{itemize}[leftmargin=*]
    \item \textbf{E1}: Data augmentation impact
    \item \textbf{E2}: Dropout regularization strength
    \item \textbf{E3}: Weight decay regularization
    \item \textbf{E4}: Learning rate scheduling
    \item \textbf{E5}: Architecture comparison (SimpleCNN vs LiteCNN)
\end{itemize}

\textbf{Baseline Configuration}:
\begin{itemize}[leftmargin=*]
    \item Augmentation: OFF
    \item Dropout: 0.25
    \item Weight decay: 0.0
    \item LR schedule: Constant
    \item Architecture: SimpleCNN
    \item Baseline validation accuracy: 62.44\%
\end{itemize}

\subsection{E1: Data Augmentation}

\subsubsection{Configuration}
\begin{itemize}[leftmargin=*]
    \item Random horizontal flip: p=0.5
    \item Random rotation: $\pm 15^\circ$
    \item Random affine: translation ($\pm 10\%$)
    \item Color jitter: brightness/contrast variation
\end{itemize}

\subsubsection{Results}
\begin{itemize}[leftmargin=*]
    \item \textbf{Validation Accuracy}: 62.66\%
    \item \textbf{Change}: +0.22\% vs baseline
    \item \textbf{Conclusion}: Marginal improvement; augmentation helps generalization slightly
\end{itemize}

Data augmentation provides a small performance boost by increasing training data diversity and reducing overfitting. The modest improvement suggests that FER2013's training set is reasonably diverse, limiting augmentation benefits.

\subsection{E2: Dropout Regularization (p=0.5)}

\subsubsection{Configuration}
\begin{itemize}[leftmargin=*]
    \item Dropout probability: 0.5 (vs baseline 0.25)
    \item All other settings: baseline
\end{itemize}

\subsubsection{Results}
\begin{itemize}[leftmargin=*]
    \item \textbf{Validation Accuracy}: 61.68\%
    \item \textbf{Change}: -0.76\% vs baseline
    \item \textbf{Conclusion}: Higher dropout hurts performance; 0.5 is too aggressive for this model

Increasing dropout from 0.25 to 0.5 reduces model capacity too much, preventing the network from learning sufficient discriminative features. This suggests SimpleCNN's capacity is already well-matched to the task, and aggressive regularization is counterproductive.

Both weight decay values show a negative relationship with accuracy. The stronger penalty (0.001) produces worse results than the weaker one (0.0001), confirming that L2 regularization is inappropriate for this architecture and dataset combination. \section{Limitations and Challenges}

\subsection{Dataset Limitations}

\subsubsection{Low Resolution and Grayscale}
FER2013's 48×48 grayscale format presents significant challenges:
\begin{itemize}[leftmargin=*]
    \item \textbf{Lost fine-grained details}: Facial landmarks like subtle eye movements or lip twitches are not captured at this resolution
    \item \textbf{No color information}: Loss of skin tone changes (blushing, blanching) which are emotion indicators
    \item \textbf{Lighting sensitivity}: Grayscale images are more susceptible to lighting variations
    \item \textbf{Compression artifacts}: Low resolution introduces pixelation that obscures features
\end{itemize}

% \end{figure}

\subsubsection{Class Imbalance}
The severe imbalance between emotion classes:
\begin{itemize}[leftmargin=*]
    \item Disgust: only 1.5\% of dataset (547 images)
    \item Happy: 25.1\% of dataset (8,989 images)
    \item 16:1 ratio between majority and minority classes
\end{itemize}
This imbalance makes minority class learning extremely difficult and biases the model toward predicting majority classes.

\subsubsection{Human Baseline}
Human accuracy on FER2013 (65-68\%) establishes an upper performance bound, indicating:
\begin{itemize}[leftmargin=*]
    \item Inherent ambiguity in emotion labels
    \item Low-quality or mislabeled samples in the dataset
    \item Fundamental difficulty of the task with 48×48 grayscale images
\end{itemize}

\subsection{Model Limitations}

\subsubsection{Domain Specificity}
The model is trained exclusively on human facial expressions:
\begin{itemize}[leftmargin=*]
    \item \textbf{No cross-species generalization}: Testing on animal faces produces low-confidence neutral predictions
    \item \textbf{Human-face assumption}: Model architecture implicitly assumes facial structure and proportions
    \item \textbf{Limited diversity}: Training data may not represent all age groups, ethnicities, or lighting conditions
\end{itemize}

\subsubsection{Temporal Information}
Static image classification ignores temporal dynamics:
\begin{itemize}[leftmargin=*]
    \item No consideration of expression transitions
    \item Cannot detect micro-expressions or expression sequences
    \item Video-based FER could leverage temporal consistency
\end{itemize}

\subsubsection{Context Blindness}
The model operates on isolated face crops:
\begin{itemize}[leftmargin=*]
    \item No body language or posture information
    \item No environmental or situational context
    \item Real-world emotion understanding requires multimodal cues
\end{itemize}

\subsection{Deployment Limitations}

\subsubsection{Latency Trade-offs}
\begin{itemize}[leftmargin=*]
    \item \textbf{SimpleCNN}: Fast (0.93ms) but lower accuracy (62.44\%)
    \item \textbf{LiteCNN}: Better accuracy (65.73\%) but slower (5.33ms)
    \item \textbf{CLCM}: Fastest (2.15ms) with moderate accuracy (60.39\%)
\end{itemize}
There remains an accuracy-speed trade-off that must be considered for specific deployment contexts.

\subsubsection{CPU-Only Constraint}
The project targets CPU deployment, which:
\begin{itemize}[leftmargin=*]
    \item Limits model complexity and size
    \item Prevents use of larger, more accurate models
    \item Constrains real-time video processing capabilities
\end{itemize}

\section{Future Work and Recommendations}

\subsection{Model Architecture Improvements}

\subsubsection{Attention Mechanisms}
Incorporating attention could improve performance:
\begin{itemize}[leftmargin=*]
    \item \textbf{Spatial attention}: Focus on emotion-relevant facial regions (eyes, mouth, eyebrows)
    \item \textbf{Channel attention}: Weight feature maps by importance
    \item \textbf{Self-attention}: Capture long-range dependencies within the face
\end{itemize}

\subsubsection{Multi-Scale Feature Fusion}
\begin{itemize}[leftmargin=*]
    \item Feature pyramid networks to capture both coarse and fine details
    \item Multi-resolution input processing
    \item Scale-aware convolutions
\end{itemize}

\subsubsection{Knowledge Distillation}
Compress larger, more accurate models into LiteCNN:
\begin{itemize}[leftmargin=*]
    \item Train a large teacher model (e.g., ResNet-50) on FER2013
    \item Use soft targets to train lightweight student model
    \item Transfer knowledge without parameter explosion
\end{itemize}

\subsection{Data and Training Improvements}

\subsubsection{Data Augmentation Strategies}
\begin{itemize}[leftmargin=*]
    \item \textbf{Class-specific augmentation}: More aggressive augmentation for minority classes
    \item \textbf{Advanced techniques}: Mixup, CutMix, AutoAugment
    \item \textbf{Synthetic data generation}: GANs for generating realistic emotion samples
\end{itemize}

\subsubsection{Class Imbalance Mitigation}
\begin{itemize}[leftmargin=*]
    \item \textbf{Class weighting}: Assign higher loss weights to minority classes
    \item \textbf{Oversampling}: SMOTE or similar techniques for disgust class
    \item \textbf{Focal loss}: Down-weight easy examples, focus on hard cases
\end{itemize}

\subsubsection{Training Data Diversification}
\begin{itemize}[leftmargin=*]
    \item \textbf{Multi-dataset training}: Combine FER2013 with RAF-DB, AffectNet
    \item \textbf{Domain adaptation}: Pre-train on larger face recognition datasets
    \item \textbf{Demographics diversity}: Ensure representation across ages, ethnicities, genders
\end{itemize}

\subsection{Deployment Optimizations}

\subsubsection{Model Quantization}
\begin{itemize}[leftmargin=*]
    \item \textbf{INT8 quantization}: Reduce model size and inference time
    \item \textbf{Mixed precision}: Maintain accuracy while reducing compute
    \item \textbf{Dynamic quantization}: Quantize at runtime without retraining
\end{itemize}

\subsubsection{Mobile and Edge Deployment}
\begin{itemize}[leftmargin=*]
    \item \textbf{TensorFlow Lite conversion}: Enable smartphone deployment
    \item \textbf{ONNX export}: Framework-agnostic inference
    \item \textbf{TensorRT optimization}: GPU-accelerated inference for edge devices
\end{itemize}

\subsubsection{Temporal Smoothing for Video}
\begin{itemize}[leftmargin=*]
    \item \textbf{Moving average filtering}: Reduce prediction jitter across frames
    \item \textbf{Hidden Markov Models}: Model emotion transitions
    \item \textbf{LSTM post-processing}: Temporal consistency enforcement
\end{itemize}

\subsection{Application Enhancements}

\subsubsection{Multi-Modal Emotion Recognition}
Combine facial expression with:
\begin{itemize}[leftmargin=*]
    \item \textbf{Voice/speech analysis}: Prosody and acoustic features
    \item \textbf{Body language}: Posture and gesture recognition
    \item \textbf{Physiological signals}: Heart rate, skin conductance
    \item \textbf{Contextual information}: Scene understanding, social context
\end{itemize}

\subsubsection{Real-World Evaluation}
\begin{itemize}[leftmargin=*]
    \item Test on unconstrained real-world images (not benchmark datasets)
    \item Evaluate robustness to occlusions (masks, glasses, hands)
    \item Assess performance across diverse lighting conditions
    \item Study cross-cultural emotion expression differences
\end{itemize}

\subsubsection{Explainability and Interpretability}
\begin{itemize}[leftmargin=*]
    \item \textbf{Grad-CAM visualization}: Show which facial regions drive predictions
    \item \textbf{Feature importance analysis}: Identify key learned features
    \item \textbf{Uncertainty quantification}: Provide confidence calibration
    \item \textbf{Failure case analysis}: Systematic study of misclassifications
\end{itemize}

\subsubsection{Architectural Innovation}
LiteCNN's design successfully balances accuracy and efficiency:
\begin{itemize}[leftmargin=*]
    \item Depthwise separable convolutions reduce computational cost
    \item Residual connections improve gradient flow and feature reuse  
    \item Progressive channel expansion maintains representational capacity
    \item Achieves 3.29\% validation improvement over SimpleCNN baseline
    \item Outperforms published lightweight baseline (CLCM) despite similar parameter budget
\end{itemize}

\subsubsection{Ablation Study Insights}
Systematic ablation experiments revealed valuable insights:
\begin{itemize}[leftmargin=*]
    \item Architecture choice has the largest impact (+3.29\%)
    \item Data augmentation provides marginal benefit (+0.22\%)
    \item Over-regularization (high dropout, weight decay) consistently hurts performance
    \item Constant learning rate outperforms cosine annealing for this task
    \item Baseline hyperparameters are well-tuned for SimpleCNN
\end{itemize}

\subsection{Challenges and Lessons Learned}

\subsubsection{Dataset Constraints}
Working with FER2013 revealed fundamental challenges:
\begin{itemize}[leftmargin=*]
    \item \textbf{Resolution bottleneck}: 48×48 grayscale limits fine-grained feature extraction
    \item \textbf{Human baseline ceiling}: 65-68\% human accuracy suggests dataset quality issues
    \item \textbf{Severe class imbalance}: Disgust class (1.5\% of data) is nearly impossible to learn well
    \item \textbf{Label ambiguity}: Many images have ambiguous or contested emotion labels
\end{itemize}

    \item \textbf{Real-time video}: SimpleCNN may be preferable
    \item \textbf{Batch processing}: LiteCNN provides better accuracy
    \item \textbf{Resource-constrained}: CLCM minimizes parameters
